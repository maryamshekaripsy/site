# وب‌سایت استاتیک خانوم شکاری

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای توسعه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار
- `index.html`: ساختار معنایی صفحه و محتوای فارسی
- `css/style.css`: طراحی، رنگ‌ها، ریسپانسیو و انیمیشن‌ها
- `js/script.js`: منوی موبایل، هدر چسبان، FAQ، اعتبارسنجی فرم و دکمه بازگشت به بالا
- `assets/images/`: محل قرار دادن تصاویر محلی پروژه

## نکات مهم پیش از انتشار
1. خدمات، معرفی، سوابق و مدارک را با اطلاعات واقعی جایگزین کنید؛ محتوای فعلی در موارد مشخص‌شده نمونه است.
2. اطلاعات تماس و لینک شبکه‌های اجتماعی را به اطلاعات واقعی تغییر دهید.
3. تعرفه‌ها و مدت جلسه‌ها هنوز قطعی نیستند و به‌صورت استعلام نمایش داده می‌شوند.
4. فرم در این نسخه استاتیک است؛ فقط اعتبارسنجی سمت مرورگر انجام می‌شود و هیچ اطلاعاتی ارسال یا ذخیره نمی‌شود. برای دریافت درخواست‌ها باید آن را به PHP یا API متصل کنید.
5. Bootstrap، Bootstrap Icons و فونت Vazirmatn از CDN بارگیری می‌شوند؛ برای کارکرد کامل به اینترنت نیاز است. برای میزبانی کاملاً آفلاین، فایل‌ها را محلی قرار دهید.
6. تصاویر نمایشی از Unsplash بارگیری می‌شوند. برای انتشار نهایی بهتر است تصاویر تأییدشده خودتان را در `assets/images/` قرار دهید و مسیرهای `src` را تغییر دهید.
